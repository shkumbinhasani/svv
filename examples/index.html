SVV: Scalable Vector Video

Every clip below is a few kilobytes. The player draws Bézier shapes, text, masks, glows and blurs at your screen's pixel density and refresh rate, so you never see fixed pixels or fixed frames. Files stream in chunks, so playback starts before the whole file arrives.
